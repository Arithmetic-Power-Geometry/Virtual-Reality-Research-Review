## Main result
Every controller pair changes the sign of its conditional reset-burden difference across G01-G04. Completion behavior also changes materially, especially in G03. Therefore the supported conclusion is a controller-by-geometry regime effect within the tested simulation benchmark, not a universal controller ranking.

## Validation boundary
No live-user study is included or proposed for this paper. No claims are made about cybersickness, presence, perceptual detectability, comfort, preference, or usability.
