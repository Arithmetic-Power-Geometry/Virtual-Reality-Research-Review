# Stage 1 — Evidence Corpus and Review Reconstruction

This folder is the Stage-1 freeze created in response to the adversarial IEEE review.

## Scientific decision
Because the original database-specific discovery exports and complete historical query logs are not preserved, the existing corpus is positioned as a **structured evidence synthesis / frozen evidence-mapping corpus**. Historical search counts are not reconstructed.

## Frozen state
174 verified registered records -> 1 exact DOI duplicate removed -> 173 canonical reports -> 2 reports not retrieved -> 171 retrieved/assessed -> 165 direct eligible + 6 supporting/context.

## Files
- FROZEN_CANONICAL_CORPUS_173.csv — complete canonical record-level disposition ledger.
- DUPLICATE_RESOLUTION.csv — exact DOI duplicate provenance.
- SEARCH_PROVENANCE_AND_REVIEW_IDENTITY.md — what is known, what is irrecoverable, and permitted review positioning.
- SCREENING_AND_DISPOSITION_CODEBOOK.md — inclusion, exclusion, retrieval, family, and denominator rules.
- CORPUS_ACCOUNTING_AND_FLOW.md — frozen numerical flow and manuscript-safe wording.
- STAGE1_COMPLETION_GATE.md — completion criteria and Stage-2 handoff.

The older Table_review_pipeline_register.csv is retained as historical provenance but is not the authoritative Stage-1 status ledger because it predates later N13 full-text closure and additions through VRR-0174. The frozen corpus in this folder is authoritative for Stage 1.
