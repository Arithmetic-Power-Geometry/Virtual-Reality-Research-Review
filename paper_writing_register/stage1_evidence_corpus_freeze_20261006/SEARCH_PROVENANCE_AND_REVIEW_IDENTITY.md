# Stage 1 Search-Provenance Audit and Review Identity Freeze

## Decision
The current evidence base is frozen as a **structured evidence synthesis / evidence-mapping corpus**, not as a retrospectively reconstructed conventional database systematic review.

This is a methodological decision, not a cosmetic wording change. The repository contains a verified evidence library and screening history, but it does **not** contain preserved raw per-database discovery exports, database-specific initial yields, complete historical query strings, or original execution dates sufficient to reproduce the earliest discovery stage. Those missing historical values are not inferred or fabricated.

## What is reproducibly known
- Registered verified bibliography records: 174.
- One exact-DOI duplicate: VRR-0060 duplicates canonical VRR-0021 (DOI 10.1109/TETC.2024.3471249).
- Canonical reports after deduplication: 173.
- Reports retrieved/assessed sufficiently for disposition: 171.
- Direct eligible VR/XR evidence: 165.
- Supporting/context evidence: 6.
- Reports not retrieved after targeted retrieval: 2.
- Canonical accounting identity: 165 + 6 + 2 = 173.

## Historical search provenance that is NOT recoverable
The repository search found no preserved source files that establish a complete historical database-by-database discovery log for Scopus, Web of Science, IEEE Xplore, PubMed, or equivalent sources; no complete original query-string register; and no trustworthy database-specific initial counts/dates from which a conventional PRISMA identification stage can be reconstructed.

Therefore:
1. no historical database yield is reported;
2. no synthetic PRISMA identification counts are generated;
3. the 174-record verified library is the earliest defensible registered boundary;
4. any future database rerun is a **new prospective search**, not a reconstruction of the historical one.

## Permitted manuscript language after Stage 1
Preferred: "structured evidence synthesis", "frozen verified evidence corpus", "evidence-mapping study", or "registered evidence-library synthesis".

Avoid unless a new prospectively logged search is executed: claims that the present 174-record library is the complete output of a reproducible database systematic search.

## Search extension rule
Any future addition must record source, exact query or citation-chasing parent, execution date, candidate identifier, deduplication result, screening decision, and reason. New records create a new corpus version rather than silently changing this freeze.
