# Stage 5 Final Manuscript Consistency Audit

## Blocking inconsistencies found
1. The authoritative manuscript still described semantic comparability as six dimensions, while Stage 2 operationalized seven: P/I/O/D/C/M/V. Final rule: seven dimensions everywhere.
2. Section 4 contained stale pre-freeze wording saying corpus size/workstream proportions remained unfrozen. Final rule: the evidence library is frozen at 174 verified, 173 canonical, 171 assessed, 165 direct eligible, 6 supporting/context, 2 not retrieved.
3. Search-method wording implied complete preservation of earliest database-query yields. Final rule: the registered evidence-library flow is preserved, but earliest raw per-database discovery yields are not retrospectively reconstructed.
4. Some limitations language said the simulation "requires live-user validation." User scope explicitly excludes live-user validation. Final rule: human transfer is outside this paper's evidential scope; no live-user study is proposed or implied.
5. "Controller-by-geometry interaction" can be read as a formal factorial interaction test. Stage 3 did not fabricate such a p-value. Final rule: use "controller-by-geometry regime dependence/reversal" unless referring to a formally fitted interaction.
6. The abstract had nine keywords. Final integration uses six: virtual reality; evidence synthesis; reproducibility; redirected walking; comparability; evaluation.

## Statistical interpretation freeze
- completion and reset burden conditional on paired completion are separate estimands;
- failed runs receive no synthetic reset score;
- Holm-adjusted inference is used for conservative pairwise declarations;
- Friedman tests are within-geometry omnibus tests;
- no factorial controller-by-geometry interaction p-value is claimed;
- no held-out-geometry result is invented.

## Novelty freeze
The paper claims no new RDW controller, adaptive selector, predictive switcher, or first geometry-aware method.

## Human-outcome freeze
No inference from the simulation to cybersickness, presence, comfort, perceptual detectability, preference, workload, usability, or deployed-user benefit.

## Framework-validation freeze
The framework is operationalized and auditable. Genuine independent inter-rater agreement has not been measured; no synthetic second-coder result or kappa is reported.

## Repository/manuscript chronology
Scientific chronology is stated as:
conceptual problem -> software/benchmark implementation -> repository execution -> immutable workflow artifacts -> forensic/statistical analysis -> manuscript evidence.

The repository is an implementation/provenance source. The manuscript must never imply that GitHub, workflow automation, or AI generated the scholarly argument or paper.
