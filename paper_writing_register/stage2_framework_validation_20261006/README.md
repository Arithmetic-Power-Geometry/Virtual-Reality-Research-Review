# Stage 2 — Framework Validation and Independent-Coding Readiness

Stage 2 responds to the IEEE-style review by converting the manuscript's conceptual framework into explicit, auditable coding rules.

## Core change
Comparability is now represented by seven dimensions E=(P,I,O,D,C,M,V). Each dimension is coded compatible (1), incompatible (0), or uncertain (U). Pair-level Gamma is 1 only when all dimensions are compatible, 0 when any dimension is incompatible, and U when no dimension is incompatible but at least one is uncertain.
