# Paper Writing Evidence Register

This folder is the manuscript-writing handoff for the Virtual Reality Research Review project.

## Primary register
`VR_Paper_Writing_Evidence_Register.xlsx` maps planned papers to completed work, analysis files, key commits, evidence/claim boundaries, and paper-readiness gates.

## Intended use
Before drafting a manuscript statement, table, figure, or result:
1. identify the relevant paper in the workbook;
2. trace the work/analysis row to the repository path;
3. verify the commit and evidence status;
4. respect the listed reproduction tier and claim boundary;
5. use only frozen results for Results-section claims.

## Current paper portfolio
- P1 — systematic evidence-first VR review: primary paper.
- P2 — reproducible redirected-walking benchmarking/failure analysis: strong second paper.
- P3 — new RDW method: conditional only; no novel algorithm is currently claimed.

## Writing gate
Manuscript drafting begins only after the relevant paper-specific evidence and experimental artifacts are frozen. A benchmark-ready C4 gap is required before a new algorithm is motivated.

This folder is a research traceability aid. It does not replace the underlying protocol, data, analysis, benchmark, or provenance files.
